# @captchafox/angular

## 2.0.0

### Major Changes

- c14a174: feat!: require Angular 16 or later

  The package is built with Angular 16, and Angular requires apps to use the same or a newer version than a library was built with. `peerDependencies` now reflect this (`>=16.0.0`). Projects on older Angular versions can keep using `@captchafox/angular@1`.
